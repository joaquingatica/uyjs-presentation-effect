### Introduciendo: el tipo base `Effect`

::left::

**Un "nuevo" concepto**

```ts
//            ┌─── Representa el tipo del resultado
//            │        ┌─── Representa el typo del error
//            │        │      ┌─── Representa dependencias
//            ▼        ▼      ▼
type Effect<Success, Error, Requirements>
```

<br />

- Describe y contiene lo que se va a ejecutar
- Las variables son un `Effect`
- Las funciones devuelven un `Effect`

::right::

**Cómo crear un Effect**

```ts
// Effect<User, never, unknown>
const program = Effect.succeed({ id: 1, name: 'John' })

// Effect<never, ParseError, unknown>
const program = Effect.fail(new ParseError('Invalid number'))

// Effect<string, HttpError, unknown>
const program = Effect.gen(function* () {
  const data = yield* fetchData
  return `Data: ${JSON.stringify(data)}`
})
```

**Cómo ejecutar un Effect**

```ts
const result = Effect.runSync(program)
const result = Effect.runPromise(program)
const result = Effect.runFork(program)
```

---

**Una "nueva" sintaxis**

`yield*` y `function* () {}`

- Los generators de siempre de JavaScript
- Un "mal" necesario para las ventajas de Effect
